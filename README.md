# Index Universal — Windows offline

Aplicație desktop de indexare relațională universală, separată de History-lab.

**Principiu:** fiecare fișă informațională se înregistrează o singură dată, iar relațiile contextualizate sunt afișate din ambele capete fără duplicarea conținutului. Numai informațiile introduse manual apar în rezultatele căutării.

Funcții în versiunea 0.1: SQLite local, fișe unice, criterii deschise, căutare, surse PDF/TXT, ancore de pagină și pasaj, două vizualizatoare paralele, arhivare/restaurare. Baza pornește goală.

**Windows:** după instalarea codului, în GitHub Actions se generează executabilul `IndexUniversal.exe`. Codul și compilarea vor fi adăugate într-un commit ulterior.

Acesta este un prototip experimental; nu efectuează automat interpretări și nu pretinde să fi indexat exhaustiv biblioteci.
